## How the Research Was Conducted

All findings documented in this repository were obtained exclusively through:

1. **Behavioral observation** — playing the game as a normal user and recording observable behavior
2. **Network traffic analysis** — inspecting publicly visible HTTP requests and responses using standard browser developer tools
3. **Client-side JavaScript analysis** — reading publicly served, client-side JavaScript files that are delivered to every user's browser
4. **Statistical inference** — conducting controlled in-game tests with variable inputs and analyzing the outputs to infer underlying formulas and logic

No tools were used to bypass authentication, intercept encrypted traffic outside the browser, access server-side systems, or violate the terms of service beyond what is necessary for passive observation.
